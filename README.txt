GEOVISOR DE RESIDUOS Y ACTUACIONES AMBIENTALES - V3

Preparado para GitHub Pages.

Contenido principal:
- Infraestructuras de gestión de residuos.
- Inventario de amianto en edificaciones públicas.
- Inventario de amianto en edificaciones privadas agregado por municipio en esta demo pública.
- Puntos de littering.
- Límites municipales.
- Franja institucional de financiación PRTR / NextGenerationEU.

Subida a GitHub:
1. Descomprima este ZIP.
2. En el repositorio, Add file > Upload files.
3. Suba index.html y la carpeta assets a la raíz del repositorio.
4. Confirme el commit.
5. GitHub Pages actualizará la web automáticamente.

Nota de seguridad:
La capa privada se ha agregado por municipio deliberadamente para esta versión alojable en GitHub Pages público. No se incluyen en el paquete las localizaciones individuales de edificaciones privadas.
