GEOVISOR DE RESIDUOS Y ACTUACIONES AMBIENTALES - V3.1

Corrección de la V3 para GitHub Pages:
- Archivos JS/CSS renombrados para evitar que el navegador reutilice versiones antiguas en caché.
- Amianto público, amianto privado agregado y littering activados de inicio para comprobar visualmente que cargan.
- Renderizado dinámico de amianto ejecutado también al iniciar el visor.
- Indicador de versión y recuentos cargados en el panel.

Subida a GitHub:
1. Descomprima este ZIP.
2. En el repositorio, Add file > Upload files.
3. Suba index.html, README.txt y la carpeta assets a la raíz.
4. Los archivos nuevos llevan sufijo -v31, por lo que no dependen de la caché de la V2/V3.
5. Confirme el commit y espere a que GitHub Pages despliegue.

Nota de seguridad:
Las edificaciones privadas continúan agregadas por municipio. No se incluyen localizaciones individuales de inmuebles privados.
